# 历史文档归档

本目录保存项目历史迭代、旧版本总结、受控试用、早期界面素材和阶段性审计记录。当前公开展示请优先查看：

- README.md
- PROJECT_STATUS.md
- docs/README.md
- docs/ARCHITECTURE_OVERVIEW.md
- docs/PRODUCTION_DEPLOYMENT.md

归档目录包括：

- `showcase/`：早期 demo、面试和截图说明；
- `screenshots/`：早期静态 UI 截图；
- `releases/`：旧版 release 与开发日志；
- `operations/`：已替代的部署规划；
- `engineering-audits/`：阶段性回归与工程审计。

归档文档保留原始历史结论，不代表当前推荐演示入口、当前产品界面或当前发布状态。
