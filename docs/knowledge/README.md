This directory contains concise, public, source-grounded product facts.

- [PROJECT_FACTS.md](PROJECT_FACTS.md) records current product capabilities and boundaries.
- [PROJECT_HISTORY.md](PROJECT_HISTORY.md) records public engineering milestones.

Use `PROJECT_STATUS.md` and `docs/PRODUCTION_DEPLOYMENT.md` as the authoritative sources for current release and production facts. Do not add personal profiles, private operation logs, credentials, local paths, or external-project workflows to this directory.
